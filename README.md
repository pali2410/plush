# Soft Objects — The Furry Collection

A standalone, interactive WebGPU and WGSL procedural plush toy collection featuring 24 adorable furry characters with real-time XPBD physics, fur groom/stroke, squish, and play interactions.

## Highlights
- **24 Unique Plush Friends**: Mochi the coral octopus, Biscuit the honey bear, Clover the floppy bunny, and 21 more.
- **Pure WebGPU & WGSL**: Real-time procedural anatomy and fur rendering without any external models or textures.
- **Interactive Soft-Body Physics**: Extended Position-Based Dynamics (XPBD) physics engine supporting squishing, tossing, stroking, and tickling.
- **Lighting & Atmosphere Controls**: Daylight, golden hour, and moonlight presets with adjustable breeze, gravity, and simulation speeds.
- **Interactive Mini-Games**: Bouncy ball, popping bubbles, treats, happy dance, and a 30-second bubble dash challenge.

## How to Run
Simply open `index.html` (or `plush-octopus.html`) in any modern web browser that supports WebGPU (such as Google Chrome, Microsoft Edge, or Firefox Nightly with WebGPU enabled).
